# Technology logos

The Tech Stack page embeds SVG marks in `src/lib/techLogos.ts`, so it does not need external image requests.

The marks come from [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), commit `28241d80f8422eaed317ef968ad1e40b6d0d9163`. The collection is distributed under CC0-1.0. Brand trademarks remain with their owners; use of a mark does not imply endorsement.

SVG shapes and catalog colors are preserved on white tiles. Browser APIs use the HTML or JavaScript platform mark; database and Supabase capabilities use their platform's mark. html5-qrcode, qrcode.react, and Papa Parse use text badges.
