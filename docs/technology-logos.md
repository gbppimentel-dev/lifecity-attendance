# Technology Logos

The Tech Stack page embeds SVG brand marks in `src/lib/techLogos.ts`. No external image request is needed at runtime.

Source: [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), commit `28241d80f8422eaed317ef968ad1e40b6d0d9163`. Simple Icons distributes its SVG collection under CC0-1.0. Brand trademarks remain the property of their respective owners; inclusion does not imply endorsement. Consult the upstream brand guidelines before changing a mark.

The original SVG shapes and catalog brand colors are preserved. Logos use white tiles so app appearance settings do not recolor them. Browser APIs use HTML or JavaScript platform marks; PostgreSQL capabilities use the PostgreSQL mark; Supabase capabilities use Supabase. These identify the platform, not a separate product logo.

The html5-qrcode, qrcode.react, and Papa Parse entries use text badges: no distinct reusable brand mark was identified in the reviewed upstream project documentation. A sample generated QR code is not treated as a project logo.

When adding a technology, verify its use in the source, add its inventory entry, and use an official or established source for any new logo. Keep this document and the README current.
