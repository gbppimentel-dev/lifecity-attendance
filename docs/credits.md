# Credits

## Interface components

Several interactions were adapted from [React Bits](https://reactbits.dev/): AnimatedContent, BorderGlow, CountUp, FoldText, GlideSelect, HoldButton, MagicBento, RubberSegment, SwipeRow, and SwipeToast. They have been adjusted to fit LifeCity's layout, colors, accessibility, and data flows.

The original references include [SwipeRow](https://reactbits.dev/micro/swipe-row) and [MagicBento](https://reactbits.dev/components/magic-bento).

The circular member-status interaction was adapted from a design by Javierrocadev on [Uiverse.io](https://uiverse.io/).

## Icons, fonts, and logos

Application icons come from [Lucide](https://lucide.dev/). The interface uses [Inter](https://rsms.me/inter/), distributed through Fontsource.

The Tech Stack page uses SVG brand marks from Simple Icons. See [technology-logos.md](technology-logos.md) for the source version and treatment of brand marks.
